# Employee Quick Start

This open-source starter is designed to run with your own model API key.

1. Extract the release archive into a writable local folder. Do not run it inside the archive viewer.
2. Run `start.cmd`.
3. Open the local URL printed by the launcher.
4. Open settings and enter your own model API key.
5. Select a workspace folder.
6. Ask the agent to complete a small local file task.
7. Run `stop.cmd` when finished.

## Data and credentials

Your credentials and runtime data stay in your local runtime directory. Do not forward a used installation folder to another person. If you want to share the starter, share a clean release archive instead.

The starter should not include model keys, sessions, attachments, local databases, logs, device credentials, or private company skills.

## Hosted services

Chongming hosted memory, enterprise knowledge bases, sales-coach workflows, and Hub skill synchronization are optional integrations. They are not required for the basic starter experience.
